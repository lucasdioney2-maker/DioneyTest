# Studio 085 — Fluxo de Demonstração com Framer

## Quando uma empresa responde com interesse → este é o processo

---

## PASSO 1 — Reunião inicial (15–30 min)

**Perguntas a fazer:**
- Qual é a história do negócio? Há quanto tempo existe?
- Quem são os vossos clientes principais?
- Têm logótipo, cores ou identidade visual?
- Têm fotos actuais (mesmo que de telemóvel)?
- O que querem que as pessoas façam ao chegar ao site? (ligar, aparecer, encomendar?)
- Estão no Instagram? Com que frequência publicam?

**O que recolher:**
- Nome legal do negócio
- Morada e horário
- Telefone e email de contacto
- Logo (se existir) ou preferências de cor
- 3–5 fotos actuais (servem para o protótipo inicial)

---

## PASSO 2 — Criar a Demo no Framer (AntiGravity)

### Configuração do Framer:
1. Abrir Framer → criar novo projecto
2. Usar o MCP do Framer (cmd-K → MCP) para conectar ao Claude Code
3. Criar as páginas: `/` (home), `/sobre`, `/servicos`, `/contacto`

### Estrutura base do site de demonstração:
```
HOME
  ├── Hero: Nome + tagline + foto de destaque
  ├── Sobre: Breve história do negócio
  ├── Serviços/Menu/Trabalhos: grid de fotos com descrição
  ├── Depoimentos: 3 avaliações do Google Maps (copy-paste)
  └── Contacto: formulário + mapa + telefone

SOBRE
  ├── História do negócio
  └── Equipa (se aplicável)

SERVIÇOS / MENU
  └── Lista ou grid com fotos e preços (se quiserem mostrar)

CONTACTO
  ├── Formulário
  ├── Horário
  ├── Google Maps embed
  └── WhatsApp button
```

### Usar avaliações reais do Google Maps:
- Copiar as 3 melhores avaliações do Google Maps do negócio
- Usar como prova social no site → muito impactante na demo

---

## PASSO 3 — Apresentar a Demo

**Como apresentar:**
- Enviar link de preview do Framer (staging URL)
- Ou reunião presencial/videochamada com ecrã partilhado
- Mostrar: desktop + mobile (Framer adapta automaticamente)

**Frases que funcionam:**
> "Isto é o protótipo com as fotos que vocês têm. Com uma sessão de fotografia profissional, fica assim..." (mostrar exemplo do portfolio)

> "Reparem que já usámos as vossas avaliações do Google aqui — os clientes novos vêem isso logo ao entrar."

> "Este site fica no ar em 1 semana. Pagam apenas os ~10€/mês de hospedagem."

## COMO CONECTAR O FRAMER AO CLAUDE CODE (MCP)

Para criar sites rapidamente usando IA:

1. Abrir o **Framer** (framer.com)
2. Criar ou abrir um projecto
3. Pressionar **Cmd+K** (Mac) ou **Ctrl+K** (Windows)
4. Pesquisar "MCP"
5. Abrir o plugin MCP
6. O Claude Code já está configurado — basta conectar

Uma vez conectado, o Claude consegue:
- Criar páginas completas
- Adicionar conteúdo automaticamente
- Ajustar cores, tipografia e layout
- Publicar o site
